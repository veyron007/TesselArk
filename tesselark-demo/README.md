# TesselArk product demo

A 69-second, 1920 × 1080 Remotion video built from real screens captured in TesselArk's local demo workspace. The video uses synthetic data and describes internal review and simulated statutory actions accurately. It makes no official filing or full product-parity claim.

## Edit and render

```bash
npm install
npm run dev
npx remotion render src/index.ts TesselArkProductDemo out/TesselArk-Product-Demo.mp4 --codec h264 --crf 18 --audio-codec aac
```

The composition is in `src/Composition.tsx`. The scene lengths, captions, app screens, narration clips and end card can be edited there in Remotion Studio.

## Refresh the source assets

Start the main TesselArk app in demo mode on `http://127.0.0.1:3001`. The screenshot script uses Playwright with a locally installed Google Chrome browser. From this video project's directory, run:

```bash
node scripts/capture-app.mjs
node scripts/generate-voiceover.mjs
node scripts/generate-soundtrack.mjs
```

`capture-app.mjs` selects the synthetic **Dev Accountant** account and records the dashboard, order detail, batch inventory, invoice checks, tax policy register, evidence library, work tasks, GST period view and statutory sandbox. It only reads the app. The narration is generated locally with the macOS Aman voice; the ambient score is generated by this project. Manrope and DM Sans are distributed under their included SIL Open Font licenses.

The generated MP4 and SRT live under `out/`. Run `npm run lint` to check the Remotion source.
